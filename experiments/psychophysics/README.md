# psychophysics — харнесс калибровки перцептивных констант

Инструмент психофизического эксперимента для мишеней реестра остатка
(`docs/empirical-residue.md`). Реализована **мишень #1 — `PAIR_CROSSOVER_Y = 0.30`**
(кроссовер полярности лейбла). Это готовый к запуску инструмент, а не проведённая
сессия: человеческие данные собирает владелец.

Зависимостей рантайма — ноль (правило репо, issue #29): вся математика написана
руками на `std` и едет под теми же гейтами CI, что и остальной воркспейс
(`fmt`/`clippy`/`test`/`doc`/`audit --workspace` на toolchain 1.96.0).

## Что калибруем

`PAIR_CROSSOVER_Y` — люминанс Y, на которой полярность лейбла на заливке
переключается: ниже кроссовера читается БЕЛЫЙ лейбл, выше — ЧЕРНИЛЬНЫЙ.
Экспозиция константы 21.69% (12 реальных якорей labui) — высший приоритет
валидации. Критерий приёмки (протокол §1): ширина 95% CI `< 0.03` по Y; если
PSE попадает в текущий интервал `(0.246, 0.423)` — принять `0.30`, иначе эскалация.

## Архитектура

Поток: `generate → сессия в браузере → analyze`.

```
паспорт labui ──▶ stimulus ──▶ manifest.json ──▶ html (офлайн-раннер)
(passport.rs)   (детермин.      │                    │
                 из seed)       │                 наблюдатель (2AFC)
                                │                    │
                                ▼                    ▼
                         swatch на Y            raw-*.json (сырые ответы)
                         (color.rs)                  │
                                                     ▼
                                       logistic (MLE) ─▶ analysis (bootstrap CI)
                                                              │
                                                              ▼
                                                        вердикт: ACCEPT / ESCALATE
```

Модули (`src/`):

| модуль | ответственность |
|--------|-----------------|
| `rng` | детерминированный ГПСЧ SplitMix64 — единый источник случайности |
| `json` | минимальный JSON (чтение паспорта, экспорт) без зависимостей |
| `color` | sRGB↔линейный, WCAG-люминанс, свотч на ЗАДАННЫЙ Y с оттенком семьи |
| `passport` | чтение замороженного паспорта labui → 10 фирменных семей |
| `stimulus` | детерминированный манифест 2AFC-сессии (порядок и стороны из seed) |
| `html` | рендер автономного офлайн-раннера со встроенным манифестом |
| `logistic` | MLE-подгонка `P(белый)=σ(a+b·Y)` (IRLS) и PSE=`−a/b` |
| `analysis` | кластерный bootstrap 95% CI PSE и вердикт по критерию приёмки |
| `synthetic` | синтетический наблюдатель — замок честности пайплайна |

Ключевые решения:

- **Свотч на заданный Y.** Люминанс — экспериментальная переменная, поэтому свотч
  строится ровно на узле сетки `Y ∈ [0.18, 0.44]` шаг 0.02: в линейном свете берётся
  вектор нулевой люминанс вдоль оттенка семьи, свотч максимально хроматичен в пределах
  гаммы. Формула Y байт-совпадает с `labcolors_core::exposure_support::wcag_y` — именно
  против неё ядро сравнивает константу. Стимулы строятся НЕЗАВИСИМОЙ математикой (не
  через `labcolors-core`), иначе эксперимент был бы циркулярным.
- **Кластерный bootstrap.** Ресэмпл НАБЛЮДАТЕЛЕЙ (не проб): N≥15 человек — выборка из
  популяции, и CI обязан отражать межнаблюдательную дисперсию.
- **Детерминизм.** Один seed → байт-идентичные манифест и раннер; воспроизводимость
  сессии и анализа.

## Runbook

Все команды — из корня воркспейса. Бинарник: `cargo run -p psychophysics -- <cmd>`.
Артефакты пишутся в `--out-dir` (по умолчанию `psychophysics-out/`, в гит не коммитится).

1. **Сгенерировать сессию** (манифест + офлайн-раннер):
   ```
   cargo run -p psychophysics -- generate --seed 424242 --out-dir psychophysics-out
   ```
   → `session-424242.json` (манифест) и `session-424242.html` (раннер).
   140 проб (10 семей × 14 узлов Y), чернильный лейбл `#101012`, белый `#FFFFFF`.

2. **Провести сессию.** Открыть `session-*.html` в браузере на калиброванном дисплее.
   Условия (чек-лист прямо в раннере, обязателен к подтверждению):
   нормальное цветовосприятие · дисплей sRGB/gamma 2.2, ~80–120 кд/м² · окружение
   близко к D65 · расстояние 50–70 см · окно на весь экран, масштаб 100%.
   Наблюдатель на каждой пробе выбирает, где надпись читается легче (мышь или `F`/`J`).
   В конце — «Скачать сырой JSON» (`psychophysics-<observer>-<время>.json`).

3. **Собрать N ≥ 15 наблюдателей.** Один файл экспорта = один наблюдатель. Для
   контрбаланса порядка выдавайте манифесты с разными seed.

4. **Проанализировать:**
   ```
   cargo run -p psychophysics -- analyze psychophysics-out/*.json --resamples 2000
   ```
   Печатает вердикт JSON: PSE, 95% CI, ширина, решение ACCEPT/ESCALATE и обоснование.
   Выход: `0` — принять, `3` — эскалация, `1` — ошибка.

Вспомогательные команды:

- `selftest` — прогон замка честности на синтетике (та же логика, что тест в CI).
- `simulate --observers 16 --out-dir DIR` — записать сырые экспорты синтетических
  наблюдателей, чтобы прогнать `analyze` вживую БЕЗ набора людей (dry-run/power-анализ).

## Замок честности (self-test)

`tests/self_test.rs` (в CI через `cargo test --workspace`) синтезирует наблюдателей с
ИЗВЕСТНЫМ PSE и логистическим шумом и требует, чтобы пайплайн восстановил истину, а
не подтверждал произвольное значение (иначе assertion-free анализ был бы театром).
Проверяется: восстановление PSE в допуске, покрытие истины 95%-интервалом,
достижение критерия CI, и что смещённая популяция НЕ «залипает» на 0.30.

Прогон `selftest` (истинный PSE=0.30, 18 наблюдателей, 2000 ресэмплов):

```
восстановленный PSE=0.2983  |ошибка|=0.0017
95% CI=[0.2896, 0.3076]  ширина=0.0180   (< 0.03 ✓)
истинный PSE внутри CI: да
вердикт: ACCEPT
```

## Расширение на мишени #3 и #4 (заметка, не реализация)

Харнесс задуман переиспользуемым; ниже — как адаптировать. Не строить сейчас.

**Мишень #3 — JND-полы (`DECORATIVE_FLOOR_MIN`=7.5, `IC_DECORATIVE_FLOOR_MIN`=15.0).**
Парадигма та же (2AFC detection), меняются два звена:
- `stimulus`: вместо свотчей на сетке Y — декоративные разделители/бордеры на шагах
  контраста Lc 5–20 на репрезентативных фонах (light/dark). Ось стимула — Lc, а не Y.
- `logistic`/`analysis`: порог берётся не на `P=0.5` (PSE), а на `P=0.75` (75% верных
  детекций) — стандартный порог 2AFC-детекции; извлечь из подгонки как
  `Y* = (logit(0.75) − a)/b`. Всё остальное (rng, IRLS, bootstrap, вердикт, раннер,
  замок честности) переиспользуется как есть. Для -ic повторить под требованием
  повышенной контрастности, перекалибровать сдвиг +7.5.

**Мишень #4 — кривая чистоты / эффект Abney (`HUE_PURITY_EXPONENT`=0.6,
`HUE_PURITY_MP_REF_RATIO`=1.5).** Отклик здесь непрерывный (сдвиг оттенка), а не
бинарный, поэтому:
- задача — не 2AFC, а метод подгонки/сопоставления оттенка (asymmetric hue matching):
  наблюдатель уравнивает воспринимаемый оттенок near-neutral цвета при росте хромы;
- `stimulus`/`html`: раннер со слайдером оттенка вместо двух панелей;
- `analysis`: логистику заменить нелинейной регрессией показателя кривой чистоты по
  измеренной компенсации hue-shift (`rng`, `json`, `bootstrap`-каркас CI, детерминизм и
  замок честности переиспользуются). Цитата: Abney (issue #27). Приоритет ниже #1–#2.
