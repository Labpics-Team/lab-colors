# Отчёт человеческих оценок

Справочник JSON, создаваемого `scripts/extract_human_ratings.py`.
Требуется Python 3.11 или новее. Сеть и дополнительные пакеты не используются.

```text
python3 scripts/extract_human_ratings.py [--mode {summary,ratings,comparisons,support}]
```

Вывод: один JSON-документ в stdout. Режим по умолчанию: `summary`.
`schema_version` задаёт версию формата, `source` описывает первичные данные,
`coverage` содержит отдельные количества исследований, участников, сессий и ответов.

## Режимы

`ratings`: исходные строки со шкалой, группой, участником, сессией,
идентификатором стимула и ответом `centipoints` в сотых балла.

`summary`: средние оценки стимулов и повторяемость рангов Спирмена между
двумя сессиями, отдельно для каждого участника и групповых средних.
Корреляция постоянных ответов равна `null`.

`comparisons`: пары стимулов, направление двухсессионного среднего и
количество участников, сохранивших, изменивших или не определивших направление.
`mean_right_minus_left` выражено в баллах шкалы 0–10 как точная рациональная дробь; исходные `centipoints` означают сотые балла.

`support`: согласие участников по clean–dirty. Для каждого стимула и группы
считает людей со средним двух сессий ниже, на уровне и выше середины шкалы,
сохраняет единодушие обеих сессий и строгие переходы через середину.
Касание середины не входит в `changed_midpoint_side`. `below_fraction`
относится к людям; `mean` остаётся средним баллом. Равенство 5 не входит в
`below_midpoint`. Это заранее заданный описательный срез шкалы, не новый
критерий принятия цвета в runtime.

`simultaneous_interval` оценивает долю участников с двухсессионным средним
строго ниже 5. Используется [Clopper–Pearson](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbici.htm)
с [поправкой Bonferroni](https://www.itl.nist.gov/div898/handbook/prc/section4/prc473.htm)
на все пары «стимул × группа». При независимых одинаково распределённых
участниках внутри группы семейство интервалов покрывает соответствующие
доли с вероятностью не ниже 95%. Зависимость разных цветов у одного человека
не требует дополнительного предположения независимости между цветами.
Отсутствие исходных строк останавливает расчёт, а не уменьшает семейство.

Уровень доверия и размер семейства находятся в `support_method`.
Там же `participants` и `responses` описывают только clean–dirty;
общий `coverage` сохраняет размеры исходного архива со всеми шкалами.
Концы интервалов округлены наружу рационально с ошибкой не более 2⁻³²;
большая ширина отражает неопределённость выборки. Репрезентативность участников
для другой популяции не установлена. Интервалы не подтверждают перенос на
новые цвета, фон, язык или конкретного человека.

## Единицы и источник

Единица выборки: `(cohort, observer)`. Повторные сессии, шкалы и производные
пары одного человека остаются зависимыми наблюдениями. `scales` сохраняет
исходные полюса: например, 10 означает dirty для cleanliness, dislike для
preference и warm для warmth. Каждая шкала имеет собственный набор ответов.

Источник: [Sato и Inoue, 2016](https://doi.org/10.7717/peerj.2751), сохранённый
архив с проверяемым SHA-256. `interpretation` указывает на данные,
уже использованные при разработке: для независимой проверки модели нужна
другая выборка. Идентификаторы стимулов принадлежат статье;
условия их сопоставления с цветом описаны в
[капсуле источника](../../proof/clean-set-srgb8/v2/NOMINAL-SPEC.md).
