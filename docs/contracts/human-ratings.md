# Отчёт человеческих оценок

Справочник JSON, создаваемого `scripts/extract_human_ratings.py`.
Требуется Python 3.11 или новее. Сеть и дополнительные пакеты не используются.

```text
python3 scripts/extract_human_ratings.py [--mode {summary,ratings,comparisons}]
```

Вывод: один JSON-документ в stdout. Режим по умолчанию: `summary`.
`schema_version` задаёт версию формата, `source` описывает первичные данные,
`coverage` содержит отдельные количества исследований, участников, сессий и ответов.

## Режимы

`ratings`: исходные строки со шкалой, группой, участником, сессией,
идентификатором стимула и ответом `centipoints` в сотых балла.

`summary`: средние оценки стимулов и повторяемость рангов Спирмена между
двумя сессиями, отдельно для каждого участника и групповых средних.
Корреляция постоянных ответов равна `null`.

`comparisons`: пары стимулов, направление двухсессионного среднего и
количество участников, сохранивших, изменивших или не определивших направление.
`mean_right_minus_left` выражено в баллах шкалы 0–10 как точная рациональная дробь; исходные `centipoints` означают сотые балла.

## Единицы и источник

Единица выборки: `(cohort, observer)`. Повторные сессии, шкалы и производные
пары одного человека остаются зависимыми наблюдениями. `scales` сохраняет
исходные полюса: например, 10 означает dirty для cleanliness, dislike для
preference и warm для warmth. Каждая шкала имеет собственный набор ответов.

Источник: [Sato и Inoue, 2016](https://doi.org/10.7717/peerj.2751), сохранённый
архив с проверяемым SHA-256. `interpretation` указывает на данные,
уже использованные при разработке: для независимой проверки модели нужна
другая выборка. Идентификаторы стимулов принадлежат статье;
условия их сопоставления с цветом описаны в
[капсуле источника](../../proof/clean-set-srgb8/v2/NOMINAL-SPEC.md).
