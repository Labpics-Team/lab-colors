# API нативного биндинга Swift

Модуль `LabColors` генерируется через UniFFI из
[`labcolors-ffi`](../../crates/labcolors-ffi/src/lib.rs).
[Сборка и проверка биндинга](../../bindings/swift/README.md) описаны отдельно.

## Результаты

`contrast` и `recheck` возвращают численные оценки контраста.
`evaluateWcag22` принимает явный критерий и возвращает решение WCAG 2.2
вместе с Q55-границами и идентичностью доказательного артефакта.
`solveContrast` выбирает нейтральный цвет по переданному контракту.
`composite` вычисляет encoded-sRGB композит; `minAlpha` возвращает
нижнюю границу прозрачности, допустимую при инверсии композита.

## Ошибки

`ColorError` различает `InvalidColor`, `InvalidAlpha`, `Failure` и
`IncompatibleCoreContract`. В `Failure` категория `FailureCategory` отделяет
доказанное отсутствие решения от незавершённого поиска и недопустимого запроса;
`code` задаёт машинную причину из descriptor ядра.
Внутренний отказ и неизвестный вариант core-контракта представлены
через `IncompatibleCoreContract`.

Нативные биндинги генерируются из собранной Rust-библиотеки.
Swift conformance проверяет совместимость этой пары во временной сборке.
Состав распространяемого пакета требует отдельной проверки; Linux-прогон
не подтверждает Apple ABI или работу на iOS.
