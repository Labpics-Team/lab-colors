## 3. Конвенции (обязательны для любого продолжателя)

- **Зелёное = прогнано.** Рапорт об успехе только с выводом команд.
- `cargo test --workspace` **НЕ покрывает** нодовые сьюты `packages/*` —
  их гоняет CI-джоб «wasm build + headless test + size»; локально прогонять отдельно.
- lint-parity: `cargo fmt` + `clippy -D warnings` @ rust **1.96.0**.
- Мердж только через PR + зелёный CI; `gh pr merge --squash --delete-branch`.
  Прямые пуши в main запрещены.
- Голдены: ре-блесс только после аудита дрейфа — каждый изменившийся байт должен
  маппиться на осознанное изменение, иначе это баг, а не блесс.
- Прод-константы солвера (`DECORATIVE_FLOOR_MIN`, `PAIR_CROSSOVER_Y`, `HUE_*`,
  весь perceptual-реестр) — менять только через науч-протокол:
  дерайвация/граундинг/декларация + пиннинг-тесты + байт-аудит.
- Научный мандат: каждая константа — (a) DERIVED / (b) GROUNDED (цитата) /
  (c) EMPIRICAL (декларация в `docs/empirical-inventory.md` + sensitivity).
  «Выдуманных» чисел не существует.
