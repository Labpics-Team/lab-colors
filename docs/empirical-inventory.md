### Follow-on: возврат терминала (c) + MODEL-CONFLICT-пометка (`science/reclassify-e-buckets`, 2026-07-07)

**Таксономия — теперь ЧЕТЫРЕ терминала**, каждая константа закрыта ровно одним:

- **(a) DERIVED** — выводится из первопринципов/стандартов; derivation-identity тест.
- **(b) GROUNDED** — опубликованное измерение с проверенной цитатой; tolerance-тест.
- **(c) INTERVAL-INSENSITIVE** (ВОЗВРАЩЁН) — точное значение ДОКАЗУЕМО не влияет на выход: низкая измеренная экспозиция (наблюдательно ≤ ~2% гаммы в этом реестре) **И** существующий тест/лок подтверждает инвариантность выхода по интервалу свипа. Это ИЗМЕРЕННОЕ утверждение о поведении, СИЛЬНЕЕ «design-choice» — константа не является свободной ручкой политики, она является нематериальной для классификационного решения, которое якобы контролирует.
- **(e) DESIGN-CHOICE** — честно задекларированная свободная ручка без доказательства нематериальности. Несёт опциональную под-пометку **MODEL-CONFLICT**, когда для константы существует РАСХОДЯЩЕЕСЯ выведенное из модели/первопринципов значение:
  - **OWNER DECISION PENDING** — модельный якорь существует и согласован, но владелец ЕЩЁ не выбрал между «перейти на модель» (→ станет (a), реальные цвета сдвинутся) и «оставить осознанным тюнингом»;
  - **ИЗМЕРЕН И ОТКЛОНЁН** — единственный строгий кандидат-вывод уже проверен и признан ХУЖЕ shipped-значения (деградация поведения замерена); вопрос закрыт замером, не требует решения владельца.

MODEL-CONFLICT — пометка ВНУТРИ терминала (e), НЕ отдельный пятый терминал: расходящийся модельный якорь не делает значение более или менее «design-choice», он лишь документирует, что альтернатива была/остаётся на столе.

### Follow-on: реоткрытие CurveParams — парадигма co-dependency (`science/e-derivation-wave` #95, 2026-07-08)

**Смена парадигмы (владелец 2026-07-08): «дизайнерского цвета не бывает».** Терминал
(e) DESIGN-CHOICE для СОЗАВИСИМОЙ константы ОТМЕНЁН как окончательный: при рефуте
СКАЛЯРНОЙ деривации константа становится КАНДИДАТОМ В ФУНКЦИЮ КОНТЕКСТА, а не
свободной ручкой. Статус `#22/#23` (гаммы) и `#24` (chroma_peak_t): **«закон не
найден ЕЩЁ, активные гипотезы»** (не терминал (e)).

**#22/#23 `gamma_light/dark` — четыре метрики step-uniformity замерены, все четыре
РЕФУТИРУЮТ скалярные прочтения; закон не найден** (эксперимент `_e95_*`, убран после
замера, нейтральный рамп `#FFFFFF→#787880→#101012`):
- **Плоский Oklab ΔE** (surround-слепой): `gamma_light≈1.07 / gamma_dark≈0.95`.
- **Плоский display sRGB-байт**: `1.10 / 0.99`.
- **Surround-aware CAM16-J'** (E1: J' под `VC(Yb=фон темы, surround light/dark)` —
  crispening, Semmelroth 1970 / Whittle; зависимость CAM16 J от Yb через n, z):
  оптимум РАСТЁТ с Yb монотонно (light `srgb_with_yb`: Yb20%→0.99, Yb95%→1.04,
  Yb100%→1.04; dark `dim_surround_with_yb`: Yb0.5%→0.90, Yb20%→1.00).
  **Направление предсказания подтвердилось** (асимметрия + плотнее у якоря темы),
  но **МАГНИТУДА далеко не дотягивает** до shipped 1.75/1.5 — CAM16-Yb-crispening
  объясняет лишь единицы % сдвига.
- **Crispening-взвешенная метрика Уиттла** (задача #108, тест
  `whittle_crispening_metric_vs_shipped_gammas` в `neutral.rs`; порогово-
  дискриминационная, НЕ appearance-модель CAM16 — параметр-free, физическая
  люминанса Y через `srgb_to_xyz`, не J'): контраст Уиттла
  `W(L) = (L − Lb) / min(L, Lb)`, `Lb = Y(#787880)` (собственный t=0.5 пивот
  кода — единственный небезарбитрарный фон, ноль свободных параметров); gamma
  фитится минимизацией дисперсии шага ΔW на каждой половине лестницы (сетка
  [0.05,4.0] шаг 0.02 + золотое сечение, БЕЗ зажатия в «практическую» полосу).
  Замер: `gamma_light_pred≈1.3471` (shipped 1.75, Δ≈−0.40),
  `gamma_dark_pred≈0.1579` (shipped 1.5, Δ≈−1.34). **РЕФУТИРОВАНА** — обе
  дельты крупные; `gamma_dark` особенно, поскольку `W` расходится при `L→0`,
  а чёрный якорь `#101012` физически тёмный (`Y≈0.0053` при `Lb≈0.190`) —
  фит убегает от сингулярности, а не воспроизводит форму crispening. Тест
  фиксирует эти дельты как регресс-лок диапазонами `(0.35..0.45)` /
  `(1.30..1.40)` (замерено, не придумано) — «репорт, не форс».

  Нюанс интерпретации (внешнее научное ревью, 2026-07-08): метрика вырождается
  на ОБЕИХ половинах лестницы. На светлой все `L ≥ Lb`, поэтому
  `W = L/Lb − 1` аффинна по Y — фит там сводится к «равным физическим
  Y-шагам», crispening не совершает работы; на тёмной `W` расходится к чёрному
  якорю (см. выше). Потому `1.3471`/`0.1579` — не «настоящие
  crispening-оптимумы», а артефакты вырождения метрики: рефут магнитуды честен,
  но «crispening-метрикой» тест является лишь наполовину.

  gamma эмиссионно-МАТЕРИАЛЬНА (перебор ломает `accent_curve_007af_sample_hex_13`),
  потому форсить любую из деривации = подлог (сменил бы отгружаемые байты). Все
  четыре испробованные скалярные/параметр-free метрики рефутированы по магнитуде —
  закон гамм остаётся открытым (не терминал (e), см. мета-правило ниже);
  требуется дальнейшая контекстная гипотеза (surround × crispening совместно,
  или иная физическая модель), либо явное признание владельцем терминала после
  исчерпания.

**#24 `chroma_peak_t` — закон КОНТЕКСТА (hue) ПОДТВЕРЖДЁН, эмиссионно-нейтрален.**
Плоское прочтение (cusp на нейтральной базе) ill-posed: база `#787880` near-серая,
её Oklab-hue = atan2-шум (0.3°). Реформулировка E2 на АКЦЕНТНЫХ семействах (hue
определён) — `chroma_peak_t(hue) = t светлотного cusp'а hue`:

| hue | cusp l_ok | chroma_peak_t |
|---|---|---|
| yellow 95° | 0.884 | 0.225 |
| green 147° | 0.871 | 0.241 |
| orange 63° | 0.765 | 0.347 |
| teal 231° | 0.759 | 0.351 |
| pink 18° | 0.634 | 0.455 |
| red 29° | 0.628 | 0.461 |
| purple 312° | 0.606 | 0.476 |
| blue 257° | 0.603 | 0.479 |

Закон ХОРОШО ПОСТАВЛЕН (без шума), значение СИЛЬНО зависит от hue (диапазон
[0.225, 0.479]); **среднее по акцентам 0.379 ≈ shipped 0.35**. Скаляр 0.35 —
приближение центрального значения hue-закона; для нейтралей (hue вырожден) —
разумный дефолт вырожденного случая. `chroma_peak_t` **эмиссионно-НЕЙТРАЛЕН**
(перебор 0.35→0.28/0.47 роняет только `curve_params_sensitivity_is_bounded`, ни

(не semver-major). Кандидат в объективизацию: `chroma_peak_t = f(hue) =` cusp-
светлота, вырождение для нейтралей.
