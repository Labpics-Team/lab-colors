# Empirical residue — что осталось hand-picked и какой эксперимент это закрывает

Спутник `docs/empirical-inventory.md`. Волна `science/constants-objectivization`
классифицировала все **25** SSOT-TRACKED констант реестра ровно в один статус и
измерила ЭКСПОЗИЦИЮ каждой чувствительной: какая доля входного пространства меняет
классификационный выход, если константа пройдёт по своему интервалу. Это
превращает вопрос «вдруг оно красит некорректно СЕЙЧАС?» в измеренную величину и
приоритизирует эксперименты.

**Инвариант волны:** ноль изменений поведения. `reference-vectors` и
`chain-invariants` байт-идентичны; продакшн-константы НЕ тронуты; добавлены только
`#[cfg(test)]`-локи и exposure-тесты. Где строгий вывод даёт значение, ОТЛИЧНОЕ от
текущего, значение НЕ меняется — помечено «конфликт вывода». (Апдейт 2026-07-06:
единственный такой конфликт — `HUE_DRIFT_PENALTY_SLOPE` — разрешён по замеру,
кандидат отклонён; см. мишень №2.)

## Статусы

- **(a) DERIVABLE** — выводится из первопринципов/стандартов; derivation-identity
  тест (значение обязано остаться байт-идентичным).
- **(b) LITERATURE-GROUNDABLE** — есть опубликованное измерение; tolerance-тест.
- **(c) INTERVAL-INSENSITIVE** — задекларирован интервал; sensitivity/exposure
  доказывает, что выход стабилен, значит точное значение нематериально.
- **(d) CALIBRATION-REQUIRED** — невыводима и чувствительна; нужен эксперимент.
- **(e) DESIGN-CHOICE** — задекларирована и конфигурируема (#31).

Итог: **(a)=4, (b)=0, (c)=7, (d)=6, (e)=8**.

## EXPOSURE-анализ

**Метод сетки:** «репрезентативная гамма» = sRGB 8-бит куб, сэмплированный каждое
8-е кодовое значение по каналу, 32^3 = **32768** представимых цветов
(`exposure_support::rgb_cube`). «Реальные входы» = **49** якорей labui из
замороженного паспорта `crates/labcolors-wasm/tests/data/labui.config.json`
(`exposure_support::LABUI_ANCHORS`). Флип-зона порогового theta = доля входа с
величиной в полосе `[lo, hi)`, где решение (величина < theta) меняется, пока theta
идёт по полосе. Все числа — снапшот воспроизводимых тестов
`cargo test -p labcolors-core exposure` (2026-07-06).

**Главный вывод экспозиции:** «красит ли некорректно сейчас» — почти нигде. Из
чувствительных только ДВЕ константы имеют существенную зону (>10%): полярностный
кроссовер пары `PAIR_CROSSOVER_Y` (21.69%, 12 реальных якорей) и наклон штрафа
дрейфа `HUE_DRIFT_PENALTY_SLOPE` (14.29%). Остальные (c) — не выше 2% или
намеренный кап. Важно: 21.69%/14.29% — доля, где значение РЕШАЕТ выход, а НЕ доля
«неправильного»; текущие значения дизайн-обоснованы, экспозиция лишь ставит
приоритет валидации.

## Остаток (d): протоколы экспериментов, приоритет по экспозиции

### 1. `PAIR_CROSSOVER_Y` = 0.30 — приоритет ВЫСШИЙ (21.69%, 12 якорей)

Провенанс сегодня: 10 Figma-якорей labui, 0 наблюдателей; консенсус-лок
подтверждает лишь чистый зазор для этих 10
(`crossover_side_is_invariant_across_palette_gap`).
- **Стимулы:** заливки-свотчи с Y в [0.18, 0.45] (шаг около 0.02), каждый показан
  с БЕЛЫМ и с ЧЕРНИЛЬНЫМ лейблом на WCAG-легальном контрасте; оттенок/хрома —
  репрезентативный набор фирменных семей.
- **Задача:** 2AFC — какой лейбл читается/предпочтительнее на свотче.
- **N >= 15** наблюдателей (нормальное цветовосприятие, калиброванный дисплей, D65).
- **Метод:** логистическая психометрическая подгонка P(белый) от Y; кроссовер = Y
  при P = 0.5 (PSE).
- **Стат-тест:** bootstrap 95% CI на PSE.
- **Критерий приёмки:** ширина CI < 0.03 Y; если PSE в текущем интервале
  (0.246, 0.423) — принять как значение, иначе эскалация владельцу.

### 2. `HUE_DRIFT_PENALTY_SLOPE` = 0.15 — приоритет ВЫСОКИЙ (14.29%); конфликт вывода РАЗРЕШЁН

**Конфликт вывода — РАЗРЕШЁН 2026-07-06 (кандидат отклонён по замеру):** строгий
кандидат — перцептивная цена дрейфа = длина хорды Oklab `2*C*sin(dh/2)`, около
`C*dh*pi/180`, откуда `penalty_scale = C*pi/180`, около 0.0026-0.0035 на градус
при C около 0.15-0.20, против текущего `slope/half_window = 0.15/30 = 0.005` на
градус. Замер на 49-якорном паспорте (l-сетка 0.05-0.95, шаг 0.01): прод-наклон
держит интерьерный оптимум на всех 43 хроматических якорях (0 прижатий к ребру);
хордовый кандидат прижимает оптимум к ребру окна ±30° на 12/43 якорях, флипает
27/43 (сдвиги до полного окна, dE_ok до 0.077). То есть кандидат не
объективизирует, а передаёт решение произвольной границе
`HUE_SEARCH_HALF_WINDOW` — интерьерный оптимум вырождается в клип по окну, и
нечувствительная константа окна становится чувствительной. Значение 0.15
остаётся калибровочным классом (d). Замок:
`derivation_rejection_locks::chord_derived_slope_rejected_degenerates_to_window_edge`
(scale.rs).
- **Если скаляр остаётся:** N >= 15, наблюдатели оценивают приемлемость оттенка
  акцентной рампы при разных штрафах дрейфа по L; подгонка компромисса
  «хрома против верности каноническому оттенку» пер-семья.
- **Критерий:** наклон, минимизирующий жалобы на дрейф при сохранении хромы.

### 3. `DECORATIVE_FLOOR_MIN` = 7.5 / `IC_DECORATIVE_FLOOR_MIN` = 15.0 — JND-пол

- **Стимулы:** декоративные разделители/бордеры на Lc-шагах 5-20 на
  репрезентативных фонах (light/dark).
- **Задача:** 2AFC детекция «отличим элемент от фона?».
- **N >= 15**; порог детекции (75% верных) = JND-пол.
- **IC:** повторить под требованием повышенной контрастности; проверить или
  перекалибровать сдвиг +7.5.
- **Критерий:** пол = измеренный JND детекции декоративного контраста.

### 4. `HUE_PURITY_EXPONENT` = 0.6 / `HUE_PURITY_MP_REF_RATIO` = 1.5 — кривая чистоты

- **Метод:** измерение эффекта Abney — сдвиг воспринимаемого оттенка near-neutral
  цветов при росте хромы; подгонка показателя кривой чистоты к измеренной
  компенсации hue-shift. Цитата: Abney (issue #27).
- **N >= 15**; экспозиция непрерывная (не бинарный флип), приоритет ниже
  (d)-мишеней 1-2.

## Коррекции провенанса, найденные волной

1. **`ACHROMATIC_CHROMA_EPS` (строка 38):** реестр заявлял f64-шум конвейера
   «меньше 1e-12». ЗАМЕР: потолок хромы истинно-серых (R=G=B) = **3.7e-8**.
   EPS=1e-7 сидит лишь **около 2.7x** выше потолка шума (не «>=4 порядка»); запас
   >=3 порядка держится ТОЛЬКО сверху (мин. представимая хрома 1.06e-3).
   Классификация корректна (EPS между границами), но нижняя полоса ТОНКАЯ — строка
   исправлена.
2. **`HUE_DRIFT_PENALTY_SLOPE` (строка 37):** derivation-конфликт хорды Oklab
   разрешён 2026-07-06 — кандидат отклонён по замеру (вырождение в клип по ребру
   окна на 12/43 якорях, см. мишень #2); значение не тронуто, отказ запинован
   замком `derivation_rejection_locks::chord_derived_slope_rejected_degenerates_to_window_edge`.
