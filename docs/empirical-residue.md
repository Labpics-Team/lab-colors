# Empirical residue — что осталось hand-picked и каким терминалом это закрыто

Спутник `docs/empirical-inventory.md`. Волна `science/constants-objectivization`
исторически классифицировала **25** SSOT-TRACKED констант реестра. Текущий
реестр содержит **24**: `LIGHTNESS_SETTLE` исключён из перцептивной политики,
поскольку контрпример опроверг его прежний статус «выведенного» порога и показал,
что это legacy-эвристика численного метода, а не научный параметр. Остальные
константы по-прежнему имеют ровно один статус, а волна
измерила ЭКСПОЗИЦИЮ каждой чувствительной: какая доля входного пространства меняет
классификационный выход, если константа пройдёт по своему интервалу. Это
превращает вопрос «вдруг оно красит некорректно СЕЙЧАС?» в измеренную величину и
приоритизирует валидацию.

**Инвариант волны:** ноль изменений поведения. `reference-vectors` и
`chain-invariants` байт-идентичны; продакшн-константы НЕ тронуты; добавлены только
`#[cfg(test)]`-локи и exposure-тесты. Где строгий вывод даёт значение, ОТЛИЧНОЕ от
текущего, значение НЕ меняется — помечено «конфликт вывода». (Апдейт 2026-07-06:
единственный такой конфликт — `HUE_DRIFT_PENALTY_SLOPE` — разрешён по замеру,
кандидат отклонён; см. мишень №2.)

## Статусы

Терминальная таксономия (решение владельца 2026-07-07) — ровно ЧЕТЫРЕ терминала,
каждая константа закрыта одним из них:

- **(a) DERIVED** — выводится из первопринципов/стандартов; derivation-identity
  тест (значение обязано остаться байт-идентичным).
- **(b) GROUNDED** — есть опубликованное измерение (цитата обязана реально
  существовать и быть проверенной); tolerance-тест.
- **(c) INTERVAL-INSENSITIVE** — точное значение ДОКАЗУЕМО не влияет на выход:
  измеренная низкая экспозиция (наблюдательно ≤ ~2% гаммы в этом реестре) **и**
  существующий тест/лок подтверждает инвариантность выхода по интервалу свипа.
  Сильнее «design-choice» — это утверждение о ПОВЕДЕНИИ, не о провенансе.
- **(e) DESIGN-CHOICE** — честно задекларированная свободная ручка: якорь на
  предсказание модели (где есть), интервал, exposure/sensitivity-доказательство
  робастности. Несёт опциональную под-пометку **MODEL-CONFLICT** (OWNER DECISION
  PENDING / ИЗМЕРЕН И ОТКЛОНЁН), когда для константы существует расходящееся
  выведенное из модели значение — см. «Резолюции мишеней» ниже.

*Историческая миграция (СКОРРЕКТИРОВАНА `science/reclassify-e-buckets`,
2026-07-07):* пятиклассная рамка волны objectivization содержала ещё
(d) CALIBRATION-REQUIRED («нужен эксперимент»). Бакет «нужен эксперимент»
терминалом не является — пула наблюдателей физически нет, задекларированная
ручка честнее выдуманного будущего эксперимента (все (d) → (a)/(b)/(c)/(e) по
существу каждой строки). `science/registry-coherence` (2026-07-07, тем же днём)
временно СВЕРНУЛ (c) в (e), аргументируя, что «интервал-нечувствительность —
доказательство робастности (e)-ручки, а не провенанс значения»; тот же день
`science/reclassify-e-buckets` признал эту свёртку ЯРЛЫКОВЫМ упрощением, не
аудитом провенанса — она смешивала под одной вывеской «design-choice» три
честно разных статуса (доказанно нематериальные / модельно-конфликтные /
генуинно свободные ручки), и ВЕРНУЛ (c) как измеренный, самостоятельный терминал
(детали и таблица разбора — «Резолюции мишеней» ниже).

Итог волны objectivization (историческая рамка): (a)=4, (b)=0, (c)=7, (d)=6,
(e)=8. **После follow-on `science/floor-derivation` (мишени #3/#4, +`QUANT_GUARD`

`science/crossover-derived` (#52 → **(a) DERIVED** по измеренному перелому ядра)

OPEN в #219/#261 и не является блокером для generic fact-only pipeline.

\* STRICT_STEP: «60%» — доля соседних Lc-шагов серой сетки в +-20% вокруг
значения, т.е. STRICT_STEP сидит РОВНО в типичном шаге сетки (по дизайну, см.
лок). Это НЕ доля мис-окраски: STRICT_STEP — граница квантования, не перцептивный
порог, поэтому перекрытие ожидаемо и безвредно. **Ре-аудит 2026-07-07:** это
также ПОЧЕМУ STRICT_STEP не получает (c) — «безвредно» здесь означает «на
разумном месте по дизайну», а не «доказанно не влияет на выход»; в отличие от
строк выше, для STRICT_STEP нет теста, показывающего инвариантность эмитируемого
цвета по интервалу вокруг значения (само значение — прямое слагаемое цели).

**Главный вывод экспозиции:** «красит ли некорректно сейчас» — почти нигде. Из
чувствительных только ДВЕ константы имеют существенную зону (>10%): полярностный
кроссовер пары `PAIR_CROSSOVER_Y` (21.69%, 12 реальных якорей) и наклон штрафа
дрейфа `HUE_DRIFT_PENALTY_SLOPE` (14.29%). Остальные ручки — не выше 2% или
намеренный кап. Важно: 21.69%/14.29% — доля, где значение РЕШАЕТ выход, а НЕ доля
«неправильного»; текущие значения дизайн-обоснованы, экспозиция лишь ставит
приоритет валидации.

### 3. `DECORATIVE_FLOOR_MIN` = 7.5 / `IC_DECORATIVE_FLOOR_MIN` = 15.0 — РАЗРЕШЕНО (`science/floor-derivation`, 2026-07-06)

Психофизика НЕ требуется — закрыто деривацией + грундингом:

- **`DECORATIVE_FLOOR_MIN` = 7.5 → (a) DERIVED** = `MODEL_LC_FLOOR` + `QUANT_GUARD`.
  `MODEL_LC_FLOOR = (LO_CLIP − LO_BOW_OFFSET) × LC_SCALE = (0.1 − 0.027) × 100 = 7.3`
  — минимальный ненулевой контраст, который вообще эмитит модель: за клипом
  `contrast_core` стартует ровно с 7.3, внутри клипа — ноль (issue #44). Полярности
  симметричны (`LO_WOB_OFFSET == LO_BOW_OFFSET`, `polarity_offsets_are_symmetric`;
  иначе floor = минимум по полярностям). Алгебраическая идентичность из GROUNDED
  APCA `0.0.98G-4g` набора → отдельная (a)-строка инвентаря #54 (литерал 7.3,
  тождество с формулой пиннится).
  - **Скан-замер** (`no_pair_emits_contrast_below_model_floor`): по квантованным
    8-бит sRGB-парам НИ ОДНА не эмитит контраст в (0, 7.3); фактический минимум
    ненулевого |Lc| = **7.3005** (0.0005 над инфимумом 7.3), скачок |Lc| одного
    8-бит шага у клипа = **7.85** (жёсткий разрыв).
  - **`QUANT_GUARD` = 0.2 → (c) EMPIRICAL** (новая строка #53; 2026-07-07: (c) → (e), см. «Статусы»). Гипотеза «0.2
    покрывает наблюдаемый шаг» ОТКЛОНЕНА замером (шаг 7.85, не 0.2); но guard'у это
    и не нужно — он держит цель (7.5) выше инфимума 7.3, чтобы квантование не
    уронило её в ноль; цель достижима в пределах `QUANT_BUDGET` = 1.0. Доминантный
    член 7.3 всё равно DERIVED.
  - Значение 7.5 — литерал (байт-идентичность; `7.3 + 0.2` в f64 ≠ 7.5 на ~1e-15),
    идентичность на компайл-тайме `const _` + `decorative_floor_is_model_floor_plus_guard`.

- **`IC_DECORATIVE_FLOOR_MIN` = 15.0 → (b) GROUNDED.** Опубликованный APCA-уровень
  Lc 15 — «absolute minimum for any non-text that needs to be discernible» (точка
  невидимости ниже неё): APCA project docs, Somers/Myndex (git.apcacontrast.com
  `WhyAPCA`, `APCA_in_a_Nutshell`). ⚠️ DRAFT/beta, single-origin, НЕ норматив
  WCAG 3 — заземление честно помечено как черновиковый дизайн-уровень, не
  независимое психофизическое измерение. IC-сдвиг +7.5 (= 15 − 7.5)
  порядкосохраняющий, пин `ic_floor_is_apca_lc15_with_order_preserving_shift`.

### 4. `HUE_PURITY_EXPONENT` = 0.6 / `HUE_PURITY_MP_REF_RATIO` = 1.5 — ЗАКРЫТЫ терминалом (e) (`science/purity-terminal-e`, 2026-07-07; разрешены как (c) в `science/floor-derivation`, 2026-07-06)

Провенанс ФОРМЫ заземлён; магнитуды — задекларированные дизайн-ручки
(терминал (e) по терминальной таксономии, решение владельца 2026-07-07),
их точное значение нематериально для хроматических якорей (инвариант
`purity == 1` при `mp ≥ mp_ref`), у near-нейтралей — ограниченный дрейф:

- **Форма** «не доверяй тону у нейтрали» мотивирована ДВУМЯ сходящимися причинами:
  (1) численной — `atan2(b,a)` ill-conditioned у серой оси; (2) перцептивной —
  эффект Abney: тон монохроматического стимула сдвигается при разбавлении белым.
  Abney (1909) Proc. R. Soc. Lond. A **83**, 120–127, DOI 10.1098/rspa.1909.0085;
  величина сдвига растёт с падением колориметрической чистоты — Kurtenbach,
  Sternheim & Spillmann (1984) JOSA A **1(4)**, 365–372, DOI 10.1364/JOSAA.1.000365.
- ⚠️ **Перцептивный Abney ОТДЕЛЁН от численного atan2-шума.** Конкретные 0.6/1.5
  НЕ выведены из данных Abney — кривая эффект Abney не моделирует (issue #27,
  `abney_correct`); Abney даёт направление коррекции, не магнитуды. Поэтому
  честный терминал магнитуд — (e), не (b): маркировка (b) была бы подлогом
  (ADR-0002/INV-2).
- **Робастность (почему (e)-ручка безопасна):** хроматические якоря
  (`mp ≥ mp_ref`) дают `purity = 1` при ЛЮБОМ показателе (инвариантны) —
  константы двигают ТОЛЬКО оттенок near-нейтралей, который и так atan2-шум.
  Свип показателя [0.4, 0.9] даёт max|Δpurity| = **0.148** — ограниченный
  непрерывный дрейф, не бинарный флип. Локи `hue_purity_curve_shape_is_pinned`,
  `exposure_hue_purity_curve`.
- Фит магнитуд к психофизическим данным (2AFC hue-shift), если когда-нибудь
  появится, станет кандидатом-ВЫВОДОМ на общих основаниях (замер → сравнение →
  решение); терминал (e) уже закрыт и этого НЕ требует.
