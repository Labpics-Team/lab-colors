# Опубликованные человеческие оценки

Исходные ответы людей доступны для повторного анализа без нового опроса.
Экстрактор использует сохранённый архив [Sato и Inoue, 2016](https://doi.org/10.7717/peerj.2751)
и его проверенный SHA-256. Дополнительные пакеты и сеть не требуются.

```sh
python3 scripts/extract_human_ratings.py > summary.json
python3 scripts/extract_human_ratings.py --mode ratings > ratings.json
python3 scripts/extract_human_ratings.py --mode comparisons > comparisons.json
```

`ratings` сохраняет шкалу, группу, участника, сессию, идентификатор стимула и
исходный ответ в сотых балла. Обе сессии и все шкалы одного участника имеют
одного владельца выборки. Деление данных при обучении выполняют по этому ключу,
сохраняя его целиком на одной стороне. Корпус уже использовался при разработке.

`summary` отдельно показывает повторяемость рангов внутри каждого участника
и повторяемость групповых средних. У постоянных ответов корреляция остаётся
неопределённой. `comparisons` сохраняет каждую пару стимулов, направление
двухсессионного среднего и случаи смены направления между сессиями. Счётчики
сравнений описывают зависимые наблюдения; количество участников указано отдельно.

Шесть шкал сохраняют исходные полюса и единицы. Больший ответ для cleanliness
означает dirty, для preference означает dislike, для warmth означает warm.
Свежесть и предпочтение доступны как отдельные измерения. Их ответы не
прибавляются к числу оценок чистоты.

Идентификаторы стимулов принадлежат исходному исследованию. Сопоставление с
экранным цветом требует отдельного контекста предъявления; условное соответствие
Table S1 описано в [капсуле источника](../proof/clean-set-srgb8/v2/NOMINAL-SPEC.md).
Показатели отчёта описывают опубликованную выборку и не меняют поведение
цветовых ограничений Program.
