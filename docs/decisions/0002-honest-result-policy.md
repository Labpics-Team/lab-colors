# ADR-0002. Честный результат: коэрсия на входе, деградация с флагом в контракте, ошибка только для программного мусора

Статус: принято (2026-07-03). Решение владельца: «пользователю не нужна
честная ошибка, нужен честный результат… это системы, убирающие головную
боль, не создающие; это обязано быть удобным без когнитивных напряжений».
Аналогия владельца: Figma на rgb(999, 999, 999) не даёт ошибку — даёт
255 255 255.

## Проблема

До этого ADR система смешивала три несовместимые реакции на «плохой» вход
без единого закона:

- `lpc()` с невалидным hex **молча считал контраст против чёрного**
  (`unwrap_or([0,0,0])`, lpc.rs) — неверный результат без сигнала: худший
  из всех исходов.
- `solve_dj` при недостижимом dJ' возвращал `Unreachable` — роль **молча
  исчезала** из эмиссии вместо ближайшего достижимого шага.
- Лестницы/альфа-аналог местами уже делали правильно: `resolve_rgba_inverted`
  поднимает α до разрешимого минимума; `enforce_text_hierarchy` компрессирует
  и ставит флаг `compressed`.

## Решение: три границы — три закона

Правило одного вопроса: **кто автор значения?**

1. **Человеческий ввод** (бренд-hex из рук, значения конфига, задаваемые
   дизайнером числа): коэрсия к ближайшему валидному значению по Постелу,
   как в Figma. Никаких ошибок за «999»; максимум — тихий флаг «скоэрсено»
   в результате. Ошибка допустима только для НЕинтерпретируемого ввода
   (не-цвет в поле цвета), и то на границе (JS/wasm), с внятным текстом.

2. **Внутренний контракт** (солвер не достигает целевого Lc/dJ', альфа
   неразрешима, композит вырожден): **деградация к ближайшему достижимому +
   честный флаг** в результате. Молчаливый клэмп запрещён (разрушает
   гарантии, на которых стоят вышележащие слои); голый `Unreachable`
   с исчезновением роли — тоже запрещён как продуктовая дыра. Эталоны
   паттерна: `compressed` у текстовой иерархии, `α_min`-подъём у
   альфа-аналога, `composite_distinct` у лестниц (этот ADR).

3. **Программный мусор** (NaN, Infinity, hex из кода, который обязан быть
   валидным по построению): честная ошибка типа `Result::Err` — это дефект
   вызывающего кода, его нельзя коэрсить в «какой-то цвет». Пример:
   альфа-гард CSS-эмиссии (NaN → Err, шум ±1e-6 у краёв [0,1] → кламп).

## Следствия (порядок внедрения)

- `TranslucentResolved::composite_distinct` — первый шаг закона 2 для
  лестниц: вырожденный композит (тинт ≈ фон, 8-битный композит равен фону)
  теперь ИЗМЕРИМ потребителем; следующий шаг — перцептивный пол FX-ролей
  (JND-деривация, отдельный слайс) и деградация α до видимости.
- `solve_dj`/`DjUnreachable`: деградация к ближайшему достижимому dJ'
  с флагом (аналог `compressed`) — отдельный слайс, меняет эмиссию.
- `lpc()` тихий чёрный: закон 3, соединить с issue #41 (fallible-API).
- Семантика тени/свечения: тень = затемнение (окклюзия), свечение =
  осветление; «elevation на тёмной теме» — это НЕ инвертированная тень,
  а осветляющий шаг, и должен называться и контрактоваться как таковой.
  Зафиксировано как направление; перевод стека на явные стороны — после
  вывода перцептивного пола FX.

## Что этот ADR запрещает

- Новые `unwrap_or(значение-по-умолчанию)` на цветовых входах (класс
  «молча неверный результат»).
- Новые ветки `Unreachable`, у которых нет либо деградации с флагом,
  либо классификации «программный мусор».
- Ошибки в ответ на интерпретируемый человеческий ввод.
