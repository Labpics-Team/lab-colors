# Проверить состав исходников и артефактов

Команды выполняются из корня полного Git checkout. Для Python-инструментов
нужен Python 3.11 или новее; версия Rust указана в корневом `Cargo.toml`.

## Сверить закреплённый инвентарь

```sh
python3 scripts/artifact_matrix.py check
```

Проверяются Git-идентичности объявленных файлов и зарегистрированные тесты.
Удаление, изменение или отключение теста требует пересмотра соответствующей
записи, а не подгонки общего числа. Для намеренного изменения обновите записи
в Linux со средой CI и включите их diff в тот же PR:

```sh
python3 scripts/artifact_matrix.py refresh
```

Перезапись записи не подтверждает корректность изменения. После неё необходимы
предметные проверки и ревью. CI только сверяет записи и не обновляет их.

## Получить манифест исходников или утверждений

```sh
python3 scripts/extract_source_files.py extract > /tmp/colors-sources.json
python3 scripts/extract_source_files.py verify < /tmp/colors-sources.json
python3 scripts/extract_claims.py extract > /tmp/colors-claims.json
python3 scripts/extract_claims.py verify < /tmp/colors-claims.json
```

Манифест исходников описывает все `.rs`-файлы `crates/labcolors-core/src`,
включая тестовые модули. Он не определяет достижимость кода при исполнении.
Манифест утверждений перечисляет синтаксические маркеры в объявленных ему
исходных корнях; он не устанавливает истинность самих утверждений.
Оба проверяющих инструмента сопоставляют запись с текущим читаемым деревом.
Недоступный каталог и символическая ссылка завершают обход ошибкой.

`extract` и `verify` на одном дереве проверяют согласованность записи с ним,
но не сравнивают изменение с предыдущей версией. За этот отдельный вопрос
отвечает закреплённый инвентарь и ревью изменения.

## Сверить файлы GitHub Actions

```sh
python3 scripts/extract_ci_build.py extract > /tmp/colors-workflows.json
python3 scripts/extract_ci_build.py verify < /tmp/colors-workflows.json
```

Учитываются файлы `.yml` и `.yaml` непосредственно в `.github/workflows`.
Проверяются схема, число записей, контрольная сумма и текущий состав файлов.
Файлы во вложенных каталогах не являются точками входа workflow.

## Проверить репозиторные метаданные на Rust

Крейт `labcolors-audit` владеет файловым обходом и извлечением метаданных Cargo,
Rust API и CI. Он не входит в зависимости математического ядра.

```sh
cargo run -p labcolors-audit --bin scanner -- .
```

Код выхода `0` означает непустой инвентарь без неоценённых, необоснованных
и дефектных записей. `1` означает, что эти условия не выполнены; `2` означает
ошибку чтения, разбора или вывода. JSON-вердикт не заменяет математические,
численные и потребительские проверки.

Планы выполнения и отчёты отдельных рабочих сессий не являются документацией
продукта. В репозитории сохраняются действующие контракты, инструкции,
эталоны, лицензии и материалы, необходимые для воспроизведения проверок.
