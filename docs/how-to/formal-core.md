# Формальная проверка ядра

Kani проверяет настоящий Rust-код Lab Colors. Проверочная сборка использует
`cfg(kani)`; обычная библиотека не получает новую зависимость или второй runtime.
Версия инструмента принадлежит `scripts/verify_core_formal.py`, перечень обязательств
и предметных отрицательных контролей находится в `scripts/formal_contracts.py`.

## Области доказательства

| Область | Проверяемое свойство | Точный предел |
|---|---|---|
| AUTH | Полная привязка разрешения, атомарный отказ, изоляция трёх ячеек, CAS, повтор и полезная цепочка вызовов | Произвольные 256-битные идентичности; истинность доказательства владельца принята как вход. Только текущий `Unverified` |
| Hex | Строгая грамматика без знаков `+`, правильный разбор обоих полубайтов, сохранность всех sRGB8-цветов | Любые байты строк длиной 0–8; полная принимаемая грамматика 6/7 байт. Более длинная строка отвергается структурным сопоставлением |
| Прозрачность | Весь binary64-допуск `[0,1]`, канонизация `-0`, точный предшественник, замкнутые интервалы и их принадлежность | Все 64 бита каждого входа, включая нечисла, бесконечности и субнормальные значения |
| Композиция | Умножение opacity на 0/1; source-over при прозрачном и непрозрачном источнике | Произвольная допустимая opacity для 0/1; любые пары байтов канала для концов source-over. Не всё непрерывное смешивание |
| Сертификаты | Точные границы чтения, отсутствие переполнения смещения, неизменность курсора при отказе `read_exact`, big-endian, длина, версия SHA | Буфер 8 байт и произвольные машинные offset/length; вся 40-байтовая grammar revision. Не полный двухмегабайтный конверт или SHA-стойкость |
| Program wire | Little-endian, отказ без сдвига курсора, сохранность всех битов f64, точный лимит количества записей | Буфер 8 байт, полный usize/u32/u64-домен проверяемых полей. Сырые NaN-биты допустимы в транспорте, не в opacity |
| Контраст WCAG | Точные точки дают исходную несокращённую дробь; решение интервала верно для любой заключённой пары целочисленных Q55-точек; полярность не меняет результат | Q55-границы `[0, 2^55+3]`; все четыре текущих критерия. Таблица яркости имеет отдельное полнодоменное численное доказательство |
| Совместный выбор | Только полный порядок без повторов, сохранность приоритета клиента, отказ при чужом ordinal и переполнении удвоения cardinality | Kani: два элемента и полные usize-ординалы; Обычные исчерпывающие тесты: 12 shape-отказов и все 256 последовательностей пар из 2×2, не выборка. Переполнение: произвольная cardinality × 2 |

Взаимосвязанные слои сохраняются: эмпирическая модель, её численная реализация,
транспорт и полномочия не удостоверяют друг друга. В частности, формальное
доказательство не превращает математический критерий в человеческий закон чистоты.

## Запуск

В разрешённой Linux x86_64 среде проверок с Rust и Python 3.11+:

```sh
cargo install kani-verifier --version "$(python3 scripts/verify_core_formal.py --kani-version)" --locked
cargo kani setup
python3 scripts/test_verify_core_formal.py
python3 scripts/verify_core_formal.py --output-dir /absolute/scratch/core-formal
```

Используется отдельный одноразовый checkout. Положительный прогон исполняет все
Kani-harness ядра: исчезнувшее или незарегистрированное доказательство меняет точный
набор и блокирует допуск. Именованные утверждения должны пройти, все обязательные
положительные и отрицательные исходы должны быть достижимы. Недостижимая защитная
ветка, сгенерированная компилятором, допустима; недостижимое обязательство не допустимо.

Затем по одному исполняются предметные мутации: неполная идентичность AUTH,
допуск `+` в hex, сохранение отрицательного нуля, неправильное смещение reader,
исключение допустимой границы wire, ослабленный порог контраста и пропуск дубля
совместного порядка. Нужен контрпример к именованному свойству. Ошибка компиляции,
памяти, тайм-аут или посторонний panic не засчитываются как найденный дефект.

JSON-отчёты, логи, воспроизводимые контрпримеры и квитанция с хешами сохраняются
артефактом задачи `formal core (Kani)` внутри обязательного CI. Публикация требует
эту задачу в успешном canonical push-run точного коммита. Старый результат не
подменяет новый запуск. Нечистый checkout не получает `source_commit` в квитанции.

## Обновление и пределы

Проверки развёртки циклов и достижимости не отключаются. У каждой proof с циклом
граница указана атрибутом; её нехватка даёт отказ, а не доказательство. Обновление
форматов, вариантов перечислений или размеров требует повторной оценки области.
Новая ветвь renderer не считается проверенной прежним `Unverified`-доказательством.

Штатное исключение восстанавливает изменённый для мутации файл. Тайм-аут завершает
всю группу решателя. Принудительное убийство Python или хоста не выполняет `finally`,
поэтому на рабочем checkout проверки не запускаются. Выделение памяти считается
успешным по стандартной модели Kani; исчерпание памяти проверяется другими тестами.

Kani, его компилятор, решатель и машинная семантика остаются доверенной базой.
Это не Lean-теорема о любой платформе. Полные доказательства умножения двух
произвольных opacity и произведения двух произвольных cardinality не входят
в этот допуск: первоначальный поиск упёрся в ресурсный предел. Частные доказанные
законы не выдаются за них. Остальные типы цветовых преобразований продолжают
проверяться независимыми численными эталонами, полным конечным перебором и тестами.
