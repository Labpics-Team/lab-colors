# Воспроизвести объявленный nominal clean-set

Из корня исходного дерева выполните с Python 3.10 или новее:

```sh
python3 scripts/verify_clean_set_receipt.py product --product-root "$PWD"
python3 scripts/verify_clean_set_receipt.py full --product-root "$PWD"
```

Первый вызов проверяет идентичности продукта, лицензии, научный выпуск,
полную proof capsule и соответствие кодека конечной таблице. Он явно сообщает
`RESEARCH_REPLAY_NOT_EXECUTED`.

Второй вызов действительно исполняет полный независимый вывод. Сначала он
проверяет каждый исходный файл по закреплённой длине и SHA-256, затем запускает
аутентифицированную копию проверяющего кода в изолированном Python. Сеть,
частный research-репозиторий и сохранённый локальный checkout не требуются.

Проверки выполняются в обычном режиме и с `python -O`: первичные ответы,
условная связь стимулов, binary64-мост текущих Rust-исходников, рациональные
сертификаты всех колонок и конечный кодек. Только после сравнения реально
полученных raw/codec байтов с продуктом выводится
`PRODUCT_AND_EXACT_NOMINAL_REPLAY_VERIFIED`. Любое отсутствие или расхождение
даёт ненулевой код завершения. Этот вызов обязателен в CI.

Для сохранения подробных результатов отдельных этапов можно запустить
поставляемую proof capsule непосредственно, выбрав новый каталог результатов:

```sh
python3 -I -B proof/clean-set-srgb8/v2/verify_bundle.py \
  --product-root "$PWD" --mode both --output-dir /tmp/labcolors-nominal-v2-proof
```

Это воспроизводит только объявленную конечную условную номинальную модель v2.
Точные предпосылки, опубликованный конфликт Table 3 и исключённые утверждения
зафиксированы в [спецификации](../../proof/clean-set-srgb8/v2/NOMINAL-SPEC.md).
Человеческая ветвь остаётся `NotRequested`, renderer — `Unverified`;
вычислительный результат не выдаёт `ProductionAuto` или `HumanAction`.

Выпуск v2 имеет новую идентичность. Исторический v1 не воспроизводится этим
вызовом: его исходный вывод не восстановлен. Сохранённая таблица v1 нужна
только для полного проверяемого [сравнения исходов](../../proof/clean-set-srgb8/v2/historical-v1/DELTA.json).
