65536 узлов, 194408 рёбер, восемь построений графа; 256 запросов на
распространение изменения для каждой плотности. Плотная выборка затрагивает
большую долю узлов, разреженная — небольшие конусы, смешанная чередует их.
Выбор между сортировкой и перечислением из уже имеющихся флагов оценивает
работу `k log2(k)` и линейный проход `n`, без подгонки по CPU.
Обратный CSR наполняется в топологическом порядке источников, поэтому вторая
глобальная сортировка рёбер не требуется. Порядок соседей и выходы сравнены
с исходной реализацией; добавлен независимый oracle для замыкания графа и
пример, где порядок предшественников не равен порядку ID.

В предыдущем сравнении четырёх языков на плотном обходе (27.11.2026)
Rust был 16.739 мс, Goose 15.101 мс, C 14.520 мс, C++ 23.514 мс.
Тот эксперимент сравнивал переписанные ядра; здесь измеряются фактические
методы библиотеки. Важно сохранить Typed errors и порядок, а не только
приблизиться к C. См. [контракт sort_unstable](https://doc.rust-lang.org/stable/std/primitive.slice.html#method.sort_unstable) для оценки сортировки. Микрозамер не доказывает ускорение всего решателя или
типичность плотных конусов в реальных продуктах.

```sh
python scripts/measure-dependency-plan.py --cpu 4 --output result.json
```

Скрипт извлекает baseline через git show и компилирует настоящий модуль
текущего checkout отдельно от остальной библиотеки.
