Ещё один слой

Тёплый материал лежит прямо на внешней поверхности. Цвет его текста связан с итогом композиции.

Роль общая, результат локальный. Кнопка, ссылка и ссылка на листе используют один исходный акцент.

Связи сохраняются. Фон, заливка и текст меняются вместе. Лист остаётся в своём контексте, а полупрозрачный слой учитывает поверхность под ним.

Связи вместо набора тем

const c = colors();
const canvas = c.surface("canvas");
const accent = c.role("accent", "#0067F4");
const ink = c.role("ink", "#242424");

const fill = accent.on(canvas);
const label = ink.on(fill, {
  contrast: "wcag22-text"
});
const link = accent.on(canvas, {
  contrast: "wcag22-text"
});

const program = await c.compile({ fill, label, link });
const view = program.attach(element, { canvas: "#E6DDD0" });
view.set({ canvas: "#283548" });
