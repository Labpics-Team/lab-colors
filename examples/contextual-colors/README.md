# Цвет в контексте

Самостоятельный интерфейс на `@labpics/colors`: одна акцентная роль на разных
поверхностях, связанная пара заливка–текст, фиксированный локальный лист и
полупрозрачный материал. Фон, исходные цвета и прозрачность меняются в самом
интерфейсе.

## Запуск

Из каталога `examples/contextual-colors`:

```sh
npm install --ignore-scripts @labpics/colors@1.2.0
npm run dev
```

Откройте адрес, который напечатает сервер; по умолчанию это
`http://127.0.0.1:4173`. Нужен Node.js 22.11 или новее.
Пример загружает установленный npm-пакет и его WASM через import map.
Отдельная сборка приложения не требуется.

## Свои роли и поверхности

В [declaration.js](declaration.js) объявлены исходные роли, локальные применения
через `.on(surface)` и переиспользуемый закон светлоты слоя. Две композиции
разные: панель → кнопка → текст и прозрачный материал → текст. Названия ролей и
связи принадлежат этому примеру.

[main.js](main.js) подключает готовую программу через `attach`, передаёт полный
контекст через `set` и заменяет authored декларацию через `replace`.
При отказе сохраняется прежний принятый интерфейс. CSS использует принадлежащие
view переменные для фактических поверхностей и текста; изменение контекста
проходит через view целиком.

В раскрываемой области «Декларация и текущий результат» видны выпущенные
значения, завершённость поиска и диагностика последней попытки.
