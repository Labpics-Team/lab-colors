# Нативный биндинг Swift

Модуль `LabColors` вызывает Rust-ядро через UniFFI. Он предоставляет измерение
контраста, оценку WCAG 2.2, перепроверку нескольких передних планов, подбор
нейтрального цвета, композит и нижнюю границу прозрачности.
Определения экспортов находятся в
[`labcolors-ffi`](../../crates/labcolors-ffi/src/lib.rs).

## Сборка

[`Package.swift`](Package.swift) связывает системный модуль `labcolorsFFI`,
сгенерированный модуль `LabColors` и conformance-тесты. Swift/C-файлы создаются
из той же Rust-библиотеки перед сборкой; отдельно взятый каталог `Sources`
не является готовым дистрибутивом.

Для локального запуска установите `RUST_TOOLCHAIN` и `SWIFT_TOOLCHAIN`
в точные версии из вызываемого CI workflow. Скрипт проверяет совпадение
установленных инструментов с этими значениями. Из корня репозитория:

```sh
export RUST_TOOLCHAIN SWIFT_TOOLCHAIN
GITHUB_WORKSPACE="$PWD" \
RUNNER_TEMP="${TMPDIR:-/tmp}" \
bash bindings/swift/ci/run-conformance.sh
```

[Скрипт](ci/run-conformance.sh) проверяет требуемые версии Rust и Swift,
собирает Rust-библиотеку, генерирует биндинги и запускает Swift-тесты.
Версии и образ CI принадлежат
[исполняемому workflow](../../.github/workflows/native-conformance-worker.yml).
[Workflow запуска](../../.github/workflows/native-conformance.yml) выбирает
его точную ревизию; при воспроизведении используйте настройки этой ревизии.

Обязательная автоматическая проверка выполняется на Linux x86_64.
Ручной macOS/arm64-прогон не заменяет проверки на Apple-платформах;
успех Linux сам по себе не подтверждает iOS или Apple ABI.

[Справочник API](../../docs/contracts/swift-binding.md) описывает результаты,

## Проверка чисел

[Conformance-пакет](../../conformance/README.md) задаёт эталоны и допуски.
[Swift-тесты](Tests/LabColorsConformanceTests/ConformanceTests.swift) сверяют
численные поля с допуском `driftTol`, композит побайтно, а HEX решателя
с допуском одной единицы 8-битного канала (±1 LSB). Для численных полей
и каналов HEX действуют разные единицы и отдельные проверки.

Согласие с эталонным пакетом проверяет реализацию объявленных операций.
Оно не удостоверяет пиксели неизвестного рендерера или восприятие человека.
